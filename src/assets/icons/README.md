# Icons PWA

Ce dossier contient les icônes de l'application pour la PWA (Progressive Web App).

## Taille des icônes requises

- icon-72x72.png (72x72 px)
- icon-96x96.png (96x96 px)
- icon-128x128.png (128x128 px)
- icon-144x144.png (144x144 px)
- icon-152x152.png (152x152 px)
- icon-192x192.png (192x192 px)
- icon-384x384.png (384x384 px)
- icon-512x512.png (512x512 px)

## Recommandations

- Format PNG avec transparence
- Fond coloré selon le thème de l'app
- Logo centré avec padding de sécurité (10%)
- Résolution exacte pour chaque taille

Vous pouvez générer ces icônes depuis le logo SVG avec un outil en ligne comme :
- https://pwa-manifest.netlify.app/ (icône unique + manifest complet)
- https://app-manifest.firebaseapp.com/

Ou utiliser un outil de génération d'icônes HD comme Figma ou Sketch.
